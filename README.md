# Jogo Rato em Busca do Queijo

Jogo desenvolvido em Python utilizando a biblioteca Pygame

O objetivo é movimentar o rato pelas setas do teclado para encontrar o queijo. Quando o rato encosta no queijo, ele aparece em outro lugar aleatório da tela.

## Como executar

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o jogo:

```bash
python main.py
```
